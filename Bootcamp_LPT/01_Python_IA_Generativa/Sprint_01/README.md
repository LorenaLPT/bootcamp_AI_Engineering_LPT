# 📘 Sprint 01 — Programación Básica I

## Bienvenido al Sprint 01

En este sprint comenzamos el camino hacia la programación en Python. Consolidaremos las herramientas del Sprint 00 y daremos los primeros pasos en el lenguaje de programación que usarás durante todo el bootcamp y tu carrera como ingeniero de IA.

Este sprint se divide en **bloques temáticos**, cada uno con su teoría y su workout.

---

## 🎯 Contenidos del Sprint

### 📖 Bloque 01 — Introducción a Herramientas

📖 [`01_Teoria/01_Introduccion_Herramientas/`](./01_Teoria/01_Introduccion_Herramientas/) · 🎯 [`02_Workout/01_Introduccion_Herramientas/`](./02_Workout/01_Introduccion_Herramientas/) · 🧪 [`Practica_live_review/01_Introduccion_Herramientas/`](./Practica_live_review/01_Introduccion_Herramientas/)

**Tema Central**: Markdown y documentación en el entorno del bootcamp

Este bloque te introduce a **Markdown**, el lenguaje de marcado que usarás para documentar tu código, escribir READMEs y comunicarte con herramientas de IA. Aunque ya configuraste las herramientas en Sprint 00, ahora aprendes a usarlas de manera efectiva.

**¿Qué aprenderás?**

- Sintaxis completa de Markdown: títulos, énfasis, listas, enlaces, imágenes
- Bloques de código y resaltado de sintaxis
- Tablas, citas, reglas horizontales
- Listas de tareas y otras características de GitHub Flavored Markdown (GFM)
- Cómo estructurar documentos claros y profesionales
- Mejores prácticas para documentación en Jupyter notebooks

---

### 🐍 Bloque 02 — Python I

📖 [`01_Teoria/02_Python_I/`](./01_Teoria/02_Python_I/) · 🎯 [`02_Workout/02_Python_I/`](./02_Workout/02_Python_I/) · 🧪 [`Practica_live_review/02_Python_I/`](./Practica_live_review/02_Python_I/)

**Tema Central**: Fundamentos de Python y programación básica

En este bloque comienzas a escribir código Python. Aprenderás los conceptos fundamentales del lenguaje: variables, tipos de datos, operaciones básicas, impresión de información y estructuras iniciales.

**¿Qué aprenderás?**

- Variables y asignación de valores
- Tipos de datos primitivos: `int`, `float`, `str`, `bool`
- Operaciones aritméticas y lógicas
- La función `print()` y salida de datos
- Conversión de tipos (casting)
- Entrada de datos desde el usuario
- Primeros pasos hacia programas interactivos

### 🔁 Bloque 03 — Flujos de Control

📖 [`01_Teoria/03_Flujos_de_Control/`](./01_Teoria/03_Flujos_de_Control/) · 🎯 [`02_Workout/03_Flujos_de_Control/`](./02_Workout/03_Flujos_de_Control/) · 🧪 [`Practica_live_review/03_Flujos_de_Control/`](./Practica_live_review/03_Flujos_de_Control/)

**Tema Central**: Tomar decisiones y repetir acciones en Python

**¿Qué aprenderás?**

- Condicionales: `if`, `elif`, `else`
- Bucles `for` y `while`, con `break` y `continue`
- Gestión básica de errores con `try`/`except`
